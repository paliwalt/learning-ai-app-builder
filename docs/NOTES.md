# Learner Notes — in my own words

_Written by the Learner, never by Claude. After each `/concept-check`,
write one or two lines per concept, in your own words, as if explaining it
to a friend who has never coded. If you cannot write the line, you do not
own the concept yet: tell Claude and it will reteach._

Format:

```
## M1 — <module name>
- C03 useState: React's way to give a component a memory. Returns the
  value and a function to change it; changing it re-renders.
- C04 ...
```
